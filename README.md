# Oakly apps

Frontends for Oakly, in one pnpm workspace. The FastAPI backend lives in its own repo; the
apps talk to it through `@oakly/api-client`, which is generated from the backend's OpenAPI spec.

| Path | What | Status |
|---|---|---|
| `apps/caregiver` | Expo app for nurses and caregivers: onboarding, job offers, visits, earnings | Active |
| `apps/admin` | Next.js admin console (caregiver approval, bookings, refunds, payouts) | Active |
| `apps/companion` | Patient web companion opened from WhatsApp links (tracking, vitals, video) | Planned |
| `packages/api-client` | Typed backend client (`openapi-fetch` + generated types) | Active |

The patient mobile app is paused; patients use WhatsApp plus the web companion (see the backend
repo's `docs/prd/`).

## Setup

```bash
corepack enable          # uses the pnpm version pinned in package.json
pnpm install
cp apps/caregiver/.env.example apps/caregiver/.env
pnpm caregiver           # expo start

cp apps/admin/.env.example apps/admin/.env.local
pnpm --filter admin dev  # admin console on http://localhost:3000 (needs the backend at OAKLY_API_ORIGIN)
```

## Keeping the API client in sync with the backend

```bash
OAKLY_BACKEND_DIR=../backend pnpm api:sync   # dumps the spec with the backend's Poetry env
# or, against a running server:
OAKLY_OPENAPI_URL=http://localhost:8000/api/v1/openapi.json pnpm api:sync
```

Commit `packages/api-client/openapi.json` and `src/schema.d.ts` together. CI fails if they disagree.
A backend change that renames or removes a field then breaks every app's typecheck at once.

## Checks (same as CI)

```bash
pnpm install --frozen-lockfile
pnpm api:generate && git diff --exit-code -- packages/api-client/src/schema.d.ts
pnpm typecheck
pnpm lint
pnpm test
pnpm --filter admin build
```

## Rules

- One React and one React Native version across the whole repo (Expo does not support duplicates).
- Never commit `.env`, keystores or signing files (see `.gitignore`).
- Native projects (`android/`, `ios/`) are generated by `expo prebuild`; configure native settings in `app.json` / config plugins.
