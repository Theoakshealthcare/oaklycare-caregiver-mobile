# SOP: Caregiver app on Expo SDK 57 (C1)

| | |
|---|---|
| **Date** | 2026-10-05 |
| **Branch** | `chore/caregiver-sdk57` |
| **Plan** | [Caregiver app plan](../plans/2026-10-05-caregiver-app.md), C1 |

## What shipped
`apps/caregiver` now runs on **Expo SDK 57** (RN 0.86.3, React 19.2.3, TypeScript 6.0.3) with
Continuous Native Generation: `android/` and `ios/` are no longer committed, and every native
setting is in `app.json` and its config plugins. Unused dependencies and dead code are gone,
tokens are in `expo-secure-store`, and the app has `typecheck`, `lint` and `test` scripts that CI runs.

## Why
- The app was on SDK 53 with committed native projects, 14 unused dependencies, an imported
  package that wasn't installed (`@react-navigation/native-stack`), hardcoded MMKV encryption
  keys, and **no type checking at all**: once enabled, the first run found 36 real errors.
- There are no users and no store release, so SDK 53 to 57 in one jump costs nothing extra.

## How
| Decision | Choice | Why |
|---|---|---|
| Upgrade | `npx expo install expo@^57 --fix`, then `expo-doctor` to 21/21 | Expo's own resolver picks compatible versions |
| Native projects | Deleted; generated by `expo prebuild`, never committed | One source of truth, and no more stale `debug.keystore` or pbxproj churn. Bundle id and package `com.oakly.oaklycaregiver` and display name were confirmed against the old native files first. |
| Token storage | `expo-secure-store` (Keychain / Keystore) behind the zustand `persist` store | Removes the hardcoded `encryptionKey` strings. `react-native-mmkv` is removed outright because nothing non-secret needed it. |
| Audio | `expo-audio` (`useAudioRecorder`) in `AINoteTaker` | `expo-av` is gone in SDK 57 |
| Camera | `DocumentScan` ported to `CameraView` / `useCameraPermissions` | The old `Camera` component API no longer exists. The fake "Document captured successfully" alert is removed: it captures and goes back, and claims nothing, since identity is decided by an admin (C2 removes the screen's remaining Onfido stubs). |
| pnpm peers | `autoInstallPeers: false`, with `@react-native/metro-config`, `@react-native/jest-preset`, `test-renderer`, `expo-asset` and `react-native-worklets` installed explicitly | `expo` lists `react-dom` / `react-native-web` / `react-native-webview` as optional peers. Auto-installing them pulled in a second, mismatched `react-dom@19.0.0`. Now the lockfile has exactly one `react` (19.2.3) and one `react-native` (0.86.3). |
| Build scripts | `onlyBuiltDependencies: []` and `ignoredBuiltDependencies` for `unrs-resolver` and `@parcel/watcher` | Neither needs its install script. Scripts are denied by default. |
| Lint | `expo lint`. The two React Compiler rules `react-hooks/set-state-in-effect` and `react-hooks/refs` are **warnings**; every other rule is an error | Old screens trip them in ways that need the C2 rewrites. The hoisting errors were fixed properly. |
| Tests | `jest-expo` + `@testing-library/react-native`, one smoke test that renders `App` and expects the onboarding slide | Mocks for reanimated, worklets and gesture-handler live in `jest.setup.ts` |

## What's involved
- **Config:** `apps/caregiver/app.json` (permissions, plugins: `expo-secure-store`, `expo-splash-screen`, `expo-location`, `expo-camera`, `expo-audio`, `expo-notifications`, `expo-asset`), `apps/caregiver/package.json`, `apps/caregiver/tsconfig.json` (extends `expo/tsconfig.base`, `strict`, `types: ["jest"]` because TypeScript 6 no longer auto-includes `@types/*`), `apps/caregiver/eslint.config.js`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `.github/workflows/ci.yml` (adds `pnpm lint`).
- **Permissions and usage strings (user-facing):**

  | Capability | iOS | Android |
  |---|---|---|
  | Location, foreground | `NSLocationWhenInUseUsageDescription` | fine and coarse |
  | Location, background | `NSLocationAlwaysAndWhenInUse...` and `NSLocationAlways...`, `UIBackgroundModes: location` | background and foreground-service location |
  | Camera and microphone | `NSCameraUsageDescription`, `NSMicrophoneUsageDescription` | `CAMERA`, `RECORD_AUDIO` |
  | Photo library | `NSPhotoLibraryUsageDescription` (via `ios.infoPlist`) | none |
  | Notifications | plugin (channel, icon, sounds) | `POST_NOTIFICATIONS` |
- **Icons:** `assets/images/icon.png` and `adaptive-icon.png` are now square 1024 px renders of the brand logo. The old config pointed at the 124x144 logo, which `expo-doctor` rejects, and the committed iOS icon was a stretched crop.
- **Removed dependencies:** `axios`, `@react-navigation/bottom-tabs`, `@react-navigation/elements`, `expo-router` (and its plugin and `typedRoutes`), `expo-blur`, `expo-haptics`, `expo-symbols`, `expo-web-browser`, `expo-linking`, `react-native-webview`, `react-native-web`, `react-dom`, `expo-av`, `react-native-mmkv`. Each was verified unimported with grep first.
- **Removed code:** `src/navigation/AuthNavigator.tsx`, root `hooks/` (template leftovers), `scripts/reset-project.js`, `src/services/storage.service.ts` (duplicate store with the hardcoded key), and the unused `Header`, `checkbox`, `date-time-picker`, `dropdown`, `popup`, `use-dimensions`, plus the React template images.
- **Real bugs the type check surfaced and fixed:** auth screens called `authService` with positional strings instead of the typed payloads (`{ email }`, `{ email, code }`, `{ token, new_password }`); list screens stored a whole `ApiResponse` as state instead of `.data`; `ProfileCompleted` navigated to a nonexistent `CaregiverDashboard` (now `BottomNavigation`); `Button` gained the `outline` variant and `leftIcon` that screens already used; theme gained the missing `successLight` and `*Text` colours; the splash screen's `fadeAnim.value` style reads were renamed to `.node` (the Reanimated 4 babel plugin warns on any `.value` in a style).
- **Not touched (C2):** login navigation, onboarding payloads, API client adoption, the auth gate, registering BookingDetails / chat / notes screens, removing the Onfido stubs (`IdentityVerification`, `FaceScan` is only declared in the param list so it type-checks).

## Verification
Run on 2026-10-05 from the repo root:
- `pnpm install --frozen-lockfile`, `pnpm api:generate` then `git diff --exit-code -- packages/api-client/src/schema.d.ts`, `pnpm typecheck` (0 errors), `pnpm lint` (0 errors, warnings only), `pnpm test` (1 app test and the 5 api-client tests) all pass.
- `cd apps/caregiver && npx expo-doctor`: 21/21 checks pass.
- `npx expo prebuild --clean --platform ios` succeeds (output not committed).
- `npx expo export --platform ios` bundles the app to Hermes bytecode (3.7 MB), so Metro, the Babel and Reanimated plugins and every import resolve.
- **Not verified: launching on the iOS Simulator.** `expo prebuild` and `pod install` succeed, but the native build fails on this machine (Xcode 26.2, Swift 6.2.3) while compiling `expo-modules-jsi@57.1.1`, a dependency of `expo`:
  - `RuntimeScheduler.h:53` and `:61`: `'RuntimeScheduler' cannot be annotated with either SWIFT_RETURNS_RETAINED or SWIFT_RETURNS_UNRETAINED because it is not returning a SWIFT_SHARED_REFERENCE type`.
  - After working around that, `JavaScriptRuntime.swift:193, 786-831` fail with `sending '...Ptr' risks causing data races`.
  - Both are Swift 6.2 compiler limits in the package's sources, not project config. The package declares `swift-tools-version: 6.2`, but SDK 57 evidently needs a newer Swift (a later Xcode 26.x). I did not commit a patch to a library that manages retain counts. No onboarding screenshot was captured.
  - Next step: install the Xcode version Expo's SDK 57 release notes require, then run `npx expo run:ios` and add `docs/sop/img/c1-onboarding.png`.

## Operate / roll back
- **Build locally:** `cd apps/caregiver && npx expo run:ios`. CocoaPods needs a UTF-8 locale: `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8`, or `pod install` crashes with a Ruby `Encoding::CompatibilityError`.
- **Native config changes:** edit `app.json` (or a config plugin), then `npx expo prebuild --clean`. Never edit `ios/` or `android/` by hand.
- **Roll back:** revert the branch. The native directories are in history at the C0 commit.
